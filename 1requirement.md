

PHASE 1
REQUIREMENT ANALYSIS
Versi : Draft 1.0
Nama Proyek
Website Desa Blumbang sebagai Media Digitalisasi Informasi Desa dan Edukasi Produk Olahan Jagung dalam Upaya Pencegahan Stunting

1. Latar Belakang
Desa Blumbang memiliki berbagai potensi yang perlu dipublikasikan kepada masyarakat, mulai dari profil desa, pelayanan publik, kegiatan masyarakat, hingga potensi hasil pertanian berupa jagung. Namun hingga saat ini informasi tersebut belum tersaji dalam media digital yang terintegrasi sehingga akses informasi bagi masyarakat masih terbatas.
Melalui program KKN, akan dikembangkan sebuah website desa yang berfungsi sebagai media publikasi resmi desa sekaligus menjadi pusat informasi mengenai potensi desa serta hasil program multidisiplin mengenai pengolahan jagung sebagai upaya pencegahan stunting. Website ini diharapkan dapat digunakan secara berkelanjutan oleh perangkat desa setelah kegiatan KKN selesai.

2. Tujuan Sistem
Tujuan Utama
Mengembangkan website Desa Blumbang sebagai media informasi digital yang mudah diakses masyarakat serta dapat dikelola secara mandiri oleh perangkat desa.

Tujuan Khusus
Menyediakan media publikasi profil Desa Blumbang.
Menyediakan informasi pelayanan publik.
Menyediakan media publikasi berita desa.
Menyediakan media publikasi pengumuman.
Menyediakan media publikasi potensi desa.
Menyediakan halaman khusus mengenai potensi dan produk olahan jagung sebagai hasil Program Multidisiplin 1.
Memberikan kemudahan bagi perangkat desa dalam mengelola informasi secara mandiri.

3. Permasalahan yang Diselesaikan
Saat ini ditemukan beberapa permasalahan, yaitu:
Belum tersedia website desa yang aktif.
Informasi desa masih disampaikan secara konvensional.
Dokumentasi kegiatan belum terpublikasi secara terpusat.
Informasi potensi desa belum terdigitalisasi.
Informasi hasil program KKN belum memiliki media publikasi yang berkelanjutan.
Perangkat desa membutuhkan media yang mudah digunakan untuk memperbarui informasi.

4. Ruang Lingkup Sistem
Website ini hanya berfokus pada digitalisasi informasi desa.
Website tidak digunakan untuk:
administrasi kependudukan,

pembayaran,

sistem arsip pemerintahan.
Website difokuskan sebagai:

Media publikasi kegiatan.
Media edukasi.
Media promosi potensi desa.

pemerintah,
wisatawan.

Administrator
Administrator merupakan perangkat desa yang bertugas mengelola seluruh informasi website.
Administrator memiliki hak untuk:

mengunggah gambar,
mengelola berita,
mengelola pengumuman.
